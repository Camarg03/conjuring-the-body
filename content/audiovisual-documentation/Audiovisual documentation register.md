# Audiovisual documentation register

This entry gathers audiovisual materials related to the research and development of *Conjuring the Body*. It functions as a working register for process videos, tests, renders, screen recordings, and external embedded media.

The materials are listed in the working order provided for the archive. Some titles come from Vimeo metadata, while others preserve internal working names used during the development of the project.
